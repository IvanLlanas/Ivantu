# Ivantu - Ivan's preferred desktop appearances
[Github repository](https://github.com/IvanLlanas/Ivantu)

## Description
Ivantu is a set of scripts to customize a GNOME 50+ appearance on Ubuntu according to my preferences.

## Installation
Just clone Ivantu from [github](https://www.github.com/IvanLlanas/Ivantu) wherever you want and launch the `start.sh` or `ivantu.sh` scripts to start the customization process.
